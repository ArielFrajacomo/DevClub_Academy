  • pnpm:

    npm install -g pnpm pnpm add express

  • Running the server:

    pnpm dev
    • creating server.js file 
      import app from './app.js'

const PORT = process.env.PORT || 3000

app.listen(PORT, () => {
    console.log(`Server is running on : http://localhost:${PORT}/`)
})
    • make sure "type": "module" is set in your package.json
    • add "dev": "node --watch src/server.js" to your scripts in package.json

  • Installing Biome.js

    Similar to ESLint, Biome.js is a tool for linting and formatting your code.
    It is a modern alternative to ESLint and Prettier, offering a unified solution for both linting and formatting.
    pnpm add -D @biomejs/biome pnpm exec biome init

    OBS: Remember to configure Biome.js, and update Open User Settings (json) to automatically format on save.
